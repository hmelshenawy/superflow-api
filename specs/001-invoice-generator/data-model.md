## Invoice Number Generation

**Format**: `{WORKSHOP_CODE}-{BRANCH_CODE}-{YEAR}-{SERIAL}`

**Example**: `GAR-DEI-2026-000001`

**Process**:
1. On invoice creation, `InvoiceNumberService` reads `workshops.code` and `branches.code`
2. Validates both codes exist:
   - If `workshops.code` is missing → throw `BadRequestException('Workshop code is required before invoices can be generated')`
   - If `branches.code` is missing → throw `BadRequestException('Branch code is required before invoices can be generated')`
   - No fallback or auto-generated replacement values are permitted
3. Determines current year
4. Executes a Prisma transaction:
   - Upsert `workshop_invoice_sequences` row for (`workshop_id`, `branch_id`, `year`)
   - Increment `last_serial_number`
   - Return the new serial
5. Formats serial as zero-padded 6 digits: `String(serial).padStart(6, '0')`
6. Concatenates: `{workshop.code}-{branch.code}-{year}-{serialPadded}`
7. Persists `invoice_number`, `invoice_year`, and `invoice_serial_number` on the invoice record

**Immutability**:
- `invoice_number` is set once at creation and never changes
- `workshop_code_snapshot` and `branch_code_snapshot` are stored on the invoice record so historical invoices remain stable even if workshop/branch codes are renamed later

**Collision Prevention**:
- `@@unique([workshop_id, invoice_number])` on `workshop_invoices` is the final guard
- Concurrent requests: Prisma transaction with `upsert` + increment blocks competing writes for the same (`workshop_id`, `branch_id`, `year`) row

## State Transitions (v1)

```
+--------+     issue      +--------+
| Draft  | -------------> | Issued |
+--------+                +--------+
    |                        |
    | cancel                 |
    v                        v
+--------+
|Cancelled|
+--------+
```

**Rules**:
- Only Draft → Issued transition is allowed for non-managers.
- Managers can edit Issued invoices (limited fields: notes only).
- Cancelled is terminal — no further transitions.
- Snapshots are locked when status becomes Issued.
- Payment tracking is excluded from v1.
